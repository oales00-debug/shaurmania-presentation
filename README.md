# Shaurmania — інтерактивна презентація

Українська презентація концепції закладу для Brussels-Central: 14 слайдів, автоматичний показ, анімація інгредієнтів, фото та порівняння приміщення «до / концепт».

## Перегляд

Відкрийте `index.html` або запустіть звичайний статичний сервер у цій папці. Збірка й установлення залежностей не потрібні.

Для GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root).

## Керування

- Стрілки або свайп — зміна слайдів.
- Кнопка «Показ / Пауза» — автоматичне відтворення.
- «Текст виступу» — нотатки до поточного слайда та джерела фотографій.
- Значок сітки — огляд усіх 14 слайдів.
- Повзунок на слайді «Простір» — порівняння реального приміщення з концепцією.

## Файли

- `index.html` — оболонка презентації та нотатки.
- `app.js` — зміст слайдів і керування показом.
- `styles.css` — адаптивний дизайн та анімація.
- `assets/` — локальні фото й шрифти.

## Фотографії

Джерела та атрибуція збережені у розділі «Фотографії та джерела» в нотатках презентації. Права на сторонні фото належать їхнім правовласникам; публікація цього репозиторію не надає окремої ліцензії на їх використання.
